# CodeBomb

C learning game made with C and raylib. / C와 raylib로 만든 C 학습 게임.

| Folder / 폴더 | What it is / 내용 |
|---|---|
| `Bravo/code_bomb/` | The integrated game: code editor + Sumin's array module. Start here. / 통합 게임: 코드 에디터 + 수민의 배열 모듈. 여기서 시작하세요. |
| `Bravo/array_module_SOO/` | Sumin's array and pointer module (standalone app, also used by the game). / 수민의 배열·포인터 모듈 (단독 앱, 게임에서도 사용). |
| `Documents-sumin/` | Sumin's development reports. / 수민의 개발 보고서. |

Build and run: see `Bravo/code_bomb/README.md`. / 빌드와 실행: `Bravo/code_bomb/README.md` 참고.
